Touch Gestures
~~~~~~~~~~~~~~

While not an exhuaustive list, this shows the most
common touch gestures available in Material Maker for Android.

In general, most desktop inputs can be mapped to
touch inputs in the following manner:

**Tap**: Left Click, **Double-Tap**: Left Double Click, **Long-Press**: Right Click

Add Node Popup
++++++++++++++
+-------------------------------------------------------+----------------------------------------------------+
| One-Finger Drag                                       | Scroll                                             |
+-------------------------------------------------------+----------------------------------------------------+
| One-Finger Drag                                       | Drag item from list (at icon)                      |
+-------------------------------------------------------+----------------------------------------------------+


Graph Editor
++++++++++++
+-------------------------------------------------------+----------------------------------------------------+
| Two-Finger drag                                       | Pan                                                |
+-------------------------------------------------------+----------------------------------------------------+
| Two-Finger Pinch | Double-Tap + Drag                  | Zoom in/out                                        |
+-------------------------------------------------------+----------------------------------------------------+
| Long Tap                                              | Add node menu                                      |
+-------------------------------------------------------+----------------------------------------------------+
| One-Finger Drag                                       | Box selection                                      |
+-------------------------------------------------------+----------------------------------------------------+
| Double Tap                                            | Enters subgraph/nodegroup, or exit/go up a level   |
|                                                       | in subgraph hierarchy when double-tapping in an    |
|                                                       | empty area.                                        |
+-------------------------------------------------------+----------------------------------------------------+
| Two-Finger Tap                                        | Undo                                               |
+-------------------------------------------------------+----------------------------------------------------+
| Three-Finger Tap                                      | Redo                                               |
+-------------------------------------------------------+----------------------------------------------------+
